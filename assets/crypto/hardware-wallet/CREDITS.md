# hardware-wallet - picture sources

Pexels has no hardware wallet (the seed-phrase and random-tokens fetches
found none). These are Wikimedia Commons photographs, downscaled to 2400px.
`ledger-laptop`, `ledger-hand`, `ledger-cable` and `trezor-confirm` were also
darkened, desaturated and vignetted to sit in the dark frame (L100-137 ->
L51-57) - a change the BY-SA licences ask us to state, so the description
says "adapted".
The CC BY / BY-SA ones need their line in the description of anything
published.
