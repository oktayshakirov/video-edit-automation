# seed-phrase

`bip39-english.txt` - the BIP39 English wordlist, 2048 words, fetched
2026-11-02 from the bitcoin/bips repository
(https://github.com/bitcoin/bips/blob/master/bip-0039/english.txt).
SHA-256 `2f5eed53a4727b4bf8880d8f3f199efc90e58503646d9ff8eff3a2ed3b24dbda`,
the published hash of the official list. Read by `beats/mnemonic.py`, which
computes every number and word it draws from it, so the phrase on screen is a
valid one. Nothing to credit in a description.
