# **The three TTS pins are the voice, and they are exact on purpose.**
# Recreating the venv from an unpinned `kokoro-onnx` resolved 0.5.0 -> 0.6.1,
# which swapped `phonemizer-fork` for plain `phonemizer` and moved onnxruntime
# 1.28 -> 1.30. The same script then synthesised 20ms longer with different
# audio bytes - a quiet change to the voice every shipped video was made in,
# and to the caption times cut against it. Caught by re-synthesising a script
# whose narration was still in the cache from the old environment.
#
# Change these deliberately or not at all. If you do change them, re-render one
# shipped cut and listen before committing.

                           # Model files (~350MB) live in ~/.local/share/kokoro.
